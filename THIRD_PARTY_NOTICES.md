# Third-party notices

This file is an attribution and review index, not a replacement for the
upstream licenses. Users who redistribute a final package must review the
license shipped with each dependency and asset.

| Component | Use in this project | Upstream / license boundary |
| --- | --- | --- |
| ROS 2 Jazzy | Middleware and interfaces | Open Robotics packages; licenses vary by package |
| Gazebo Harmonic / DART | Simulation and physics | Open Robotics / DART upstream licenses |
| MoveIt 2 | Motion planning and PlanningScene | MoveIt upstream license |
| Franka/Panda descriptions | Robot model and semantics | Upstream Franka/MoveIt resource terms |
| Ultralytics YOLO11 | Detection runtime and pretrained checkpoints | Ultralytics software/model terms apply independently |
| OpenCV, NumPy, PyYAML, PyTorch | Runtime and development dependencies | Respective upstream licenses |
| Zenodo record 6126677 | Real-image strawberry dataset | CC BY 4.0, as recorded by the project data manifest |

Large datasets, model weights, build products, and generated runtime outputs
are intentionally not licensed as project-authored source and are normally
excluded from Git. Reproduction instructions identify the expected source and
content hashes.

Project-specific visual and Blender asset provenance is indexed in
`ASSET_PROVENANCE.md` and the detailed records under `docs/assets/`.
