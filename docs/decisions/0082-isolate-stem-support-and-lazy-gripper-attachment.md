# ADR 0082：开发挂接后端隔离果梗支撑并按需挂接夹爪

- 日期：2026-09-18
- 状态：接受开发选项；不推广为默认或验收通过结论

## 背景

广义仿真把果梗固定到机械臂底座，并使用插入时自动 attached 的夹爪挂接插件。暂停启动的 ECM 出现双输入支撑；果实与机械臂还可能共享物理树，影响接触过滤。历史 joint5 的运动异常尚未确定精确物理根因。

## 决定

增加显式 `gripper_attachment_backend:=lazy`：启动不建立夹爪约束；双指接触门通过后先确认果梗释放，再夹爪挂接；果实已有其他输入约束时不创建第二条。广义 lazy 场景使用独立世界固定果梗支撑，并物化新的 world，不修改原始或历史场景。

请求确认必须收到请求后的匹配状态。失败取消待挂接意图，不进行未经验证的果实复位或果梗重挂接。默认 `upstream`、控制器、安全阈值、真值隔离与成熟度策略保持不变。

## 后果与推广门

新增一个 Jazzy/Harmonic C++ 插件包和有限范围的启动参数。ECM attached 不是独立物理成功证据；完整接触、果实随动、入箱、回零及多果资格门通过前不推广默认后端。

开发种子 45504 的 DART 运行已确认双指接触和无双支撑换手，但对准/回零仍失败。因此本决策消除有证据的结构性风险，不宣称解决历史运动异常。Bullet 对比保持开发专用，不因局部表现较好而直接更换默认引擎。
