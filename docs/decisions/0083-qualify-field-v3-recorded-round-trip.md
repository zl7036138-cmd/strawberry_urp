# ADR 0083：用预检路线库与实走轨迹反向回放闭合 field-v3 单果往返

- 日期：2026-09-23
- 状态：接受固定 field-v3 非正式开发基线；不推广为广义多果验收

## 背景

field-v3 的感知、接近、双指接触、挂接和搬运已经可以重复到达料箱附近，
但先后暴露出三个不同问题：

1. 原清空走廊在跨越机械臂底座时，腕部相机或手指会与
   `panda_link5` 自碰；
2. 果实解除刚性挂接后，落下的果实可能在数个仿真帧内顶住单侧手指，
   使第一次开爪结果超出 3 mm 位置容差；
3. 已经进入料箱后若直接重新规划回零，可能扫过料箱或未采果，重新引入
   已诊断的 joint5 接触异常。

这些问题不应通过关闭夹取前碰撞检查、放宽关节容差或忽略控制器失败来
掩盖。

## 决定

- PLACE 使用有序的有限路线库：先检查 `clear_corridor`，其四个腕滚转分支
  均不可行时，再检查 `direct_overhead` 的四个分支。
- 每个候选在发送控制命令前，必须通过完整且连续的 IK、关节界限和碰撞
  预检；八个候选均失败时保持零运动。
- `direct_overhead` 先垂直抬升，在高位完成重定向与跨区平移，到达料箱
  正上方后才下降。
- 完整 PLACE 成功后保存实际发送给控制器的全部关节段。释放与入箱验证
  之后，先用当前开爪场景重新预检所有反向段，再按逆序执行，回到安全
  撤离检查点后才允许规划 home。
- 释放开爪允许一次相同目标、一个停稳采样周期后的有界重试。两次均未
  达标仍失败关闭。
- PLACE 若已开始控制器运动却未完成，不存在完整可验证的反向路线，系统
  解除挂接并开爪后停止；禁止从未知中间状态直接长扫回零。
- 夹爪关闭的位置余差仅在匿名接触分类为 `BILATERAL_SAME_FRUIT` 时可交给
  后续严格挂接服务复核；其他接触分类仍执行原有一次开合重试并失败关闭。

该结论只证明固定 field-v3 场景、固定目标的一次最新代码完整闭环，并恢复
该场景的可工作基线。它不证明随机多植株、多目标连续采摘、正式 30 种子
门、果实无损、真实硬件或 sim-to-real。广义多果主线仍需独立资格批次。
